# Governance

OpenCreator is currently maintained by [xwcai999](https://github.com/xwcai999).

Each repository owns its releases, compatibility policy, and security fixes. Changes to the shared contract require an issue or pull request explaining affected projects. Maintainers may reject changes that mix private production data with reusable source, weaken human-confirmation gates, or obscure third-party licensing.

The project is not affiliated with or endorsed by OpenAI, MiniMax, xAI, ByteDance, or any publishing platform.
