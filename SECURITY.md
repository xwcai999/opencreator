# Security policy

Do not report secrets or private content in a public issue. Use GitHub's private vulnerability reporting for this repository when available. Otherwise contact the maintainer through the private channel listed on the maintainer's GitHub profile.

Reports should identify the affected repository and version, explain impact, and include the smallest safe reproduction. Remove credentials, user works, model transcripts, browser data, and service identifiers.

OpenCreator treats external files, model output, and bundled references as untrusted input. Integrations should use least privilege and require human confirmation before external publication or irreversible writes.
